About the Project

Player Performance Metrics is a platform that allows users to analyze and compare player statistics with interactive visuals.

Objective

To provide an intuitive interface for football analysts and fans to track player performance using structured data and visualizations.

Key Features

    Search and view player profiles.

    Compare players with performance charts.

    Graphical representation of key stats.

    Real-time updates of player statistics.

Technologies Used

Built with Flask, SQLite, HTML, CSS, JavaScript, and Chart.js for visualization.
