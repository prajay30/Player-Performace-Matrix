# Player Performance Matrix ⚽📊

A web-based application for analyzing, comparing, and visualizing player performance using statistical data.

## About the Project

**Player Performance Matrix** is a data-driven web application designed to make player performance analysis easier and more accessible. The application provides player profiles, performance statistics, comparison features, and interactive visualizations to help users understand player performance.

## Features

* Player profile management
* Player search functionality
* Player-to-player comparison
* Performance statistics
* Interactive charts and graphs
* Data-driven performance analysis
* SQLite database integration
* Simple and user-friendly interface

## Performance Metrics

The application analyzes key performance metrics such as:

* Goals
* Assists
* Shots on Target
* Passes
* Tackles Won
* Distance Covered

## How to Run

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project folder

```bash
cd Player-Performance-Matrix
```

### 3. Install the required packages

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
python app.py
```

### 5. Open in your browser

```text
http://127.0.0.1:5000/
```
